# Signal Service docs workspace

This repo is about architecture decisions, RFC drafts, and occasional meeting
fragments. Signals of process are mixed across folders:

- `rfc/` for standards proposals (including one malformed frontmatter sample)
- `decisions/` for decision-thread records
- `notes/` for meeting-style text, pasted threads, and action fragments

Some files have `status` and `owner` style markers, but there is no single, canonical meeting-note folder.
