# Atlas Sync monorepo (partial)

Main code is in `src/`, planning lives partly in `docs/plans/`, and call notes are
mixed into `docs/notes/` without a stable convention.

The planning folder is intentionally spotty:
- some entries include `status` and `owner` markers
- some filenames include dates while others are plain names
- meeting-style notes are present in bodies rather than consistently in filenames

Transcript and raw notes are ad-hoc, not part of one capture convention.
