# codebase-plans-folder repair policy

## 3 Repair Policy Pass
- No-op: capture can start now; no existing code/docs need to move.
- Minimal reversible: create/add new notes only under docs/meetings, adjacent to docs without touching docs/plans.
- Medium convention: add a lightweight meeting-note template if the team accepts dates and owner/action blocks.
- Heavy migration: reorganize existing plans/notes only after a repo-owner review and backup.

Approval boundary: any move, rename, dedupe, import materialization, or cache-state rewrite requires explicit approval. New capture destination creation is additive.
