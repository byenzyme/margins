# Living artifacts

A useful knowledge tool changes the artifact people already return to. It does not win by making a better snapshot somewhere else.

The practical test is return-to-work: after memory of the conversation fades, can someone find the live decision, understand its boundary, and reach the evidence without reconstructing the meeting? Freshness and provenance matter more than polish.
