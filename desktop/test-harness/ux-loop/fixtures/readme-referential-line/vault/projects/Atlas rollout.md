# Atlas rollout

Atlas is an experiment in carrying decisions from conversations back into the workspace where the team will act on them. The product is successful only if people can resume work without asking for the meeting to be retold.

## Current shape

- Source meeting notes land beside existing project material.
- Claims should remain traceable to the meeting evidence that produced them.
- Updates to canonical project pages require review during the pilot.

## Pilot question

Does a connected meeting note provide enough continuity, or does the project page also need a reviewed roll-up? See [[meetings/2026-03-12 Atlas review with Rui|Atlas review with Rui]] for the original source-of-truth concern.
