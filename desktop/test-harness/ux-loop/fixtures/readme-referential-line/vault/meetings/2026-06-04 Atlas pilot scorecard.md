# Measure the return to work

Leah and I sketched the first Atlas pilot scorecard. Counting recordings, generated summaries, or same-day satisfaction would measure production rather than usefulness.

The stronger observation happens after forty-eight hours: can the participant reopen the project, name the decision and unresolved boundary, and locate the source without searching chat or asking for a retelling? This extends the continuity test in [[principles/Living artifacts|Living artifacts]].

We did not decide whether the pilot should include automated project-page updates. That remains downstream of proving the connected meeting note.
