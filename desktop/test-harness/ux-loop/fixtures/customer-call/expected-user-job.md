# Expected user job

A post-meeting reviewer wants to turn a dense customer call into a trusted
Obsidian note.

The generated note should:

- capture that the customer does not want another admin dashboard;
- distinguish note-as-proof from provenance-as-secondary evidence;
- include pilot scope, permission copy, sample notes/recordings, and skeptical
  user selection as action items;
- preserve the open question about provenance without clutter;
- mention refinement as part of the trust loop;
- avoid dumping the whole transcript;
- stay readable in roughly two minutes.
